# Find It Funded - Clean GitHub Pages Website

This is the cleaned static version of the Find It Funded website.

## Upload these files to a new GitHub repository

Upload everything in this folder directly to the repository root:

- index.html
- styles.css
- thank-you.html
- 404.html
- favicon.ico
- favicon.svg
- .nojekyll
- .gitignore
- README.md

## GitHub Pages setting

Go to: Settings > Pages > Deploy from branch > main > /root > Save

## Important

Do not upload the old folders:

- node_modules
- dist
- src
- .git

This version does not need React, Vite, npm, or a build command.

## Lead form

The form currently sends to FormSubmit using support@find-it-funded.com.
The first submission may require email confirmation from FormSubmit.
After confirmation, future seller leads should forward to that email.
